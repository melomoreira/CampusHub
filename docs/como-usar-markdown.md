# Como editar a documentação Markdown

Markdown é uma sintaxe simples para formatar texto. Os arquivos usam a extensão `.md`.

## No GitHub
1. Abra o repositório.
2. Selecione **Add file → Create new file**.
3. Digite o caminho, por exemplo `docs/planejamento.md`.
4. Escreva o conteúdo usando Markdown.
5. Confira em **Preview**.
6. Selecione **Commit changes**.

## No VS Code
1. Clone o repositório.
2. Abra a pasta no VS Code.
3. Crie ou edite arquivos `.md`.
4. Confira a pré-visualização Markdown.
5. Faça commit e push.

## Sintaxe básica
- `# Título` cria título principal.
- `## Subtítulo` cria subtítulo.
- `**texto**` deixa em negrito.
- `- item` cria lista.
- `` `codigo` `` destaca código.

## Mermaid
Os diagramas UML desta pasta usam Mermaid dentro de blocos de código. O GitHub renderiza Mermaid em arquivos Markdown. Para visualizar localmente, pode ser necessária uma extensão Mermaid no VS Code.
